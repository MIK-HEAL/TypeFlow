# 高级皮肤布局

在主界面选择皮肤，点击“高级布局自定义…”。编辑器只处理原生皮肤数据和静态资源，不创建第二个 Rime 引擎，也不修改原 SSF。

## 操作

- 左侧选择背景、拼音、候选或装饰图层；在画布中也可直接选择可见元素。
- 拖动文字或图片定位；选中画布元素后，方向键移动 1 DIP，Shift＋方向键移动 10 DIP。透明区域内的图层仍按矩形范围选取；被遮挡的图层可通过左侧列表选择。
- 右侧数值按 Enter 或离开输入框后生效；非法参数标红，并保持上次有效预览。修正后才能保存。
- 用“添加装饰图片”导入 PNG、JPEG 或 BMP 静态图片。新增素材复制并规范化为包内 PNG；移动原图片不影响保存后的皮肤。多帧文件不支持。
- 图层可设置九个锚点、X/Y 偏移、尺寸、不透明度、显示状态和文字上方／下方。尺寸为 0 时使用源图大小。负偏移允许将装饰部分移出画布，超出部分裁剪。
- 同一绘制平面中的图层按列表顺序从后向前绘制；“前移／后移”调整该顺序。绘制平面优先于列表顺序：文字上方图层总在文字和下方图层之后。
- 拼音和候选有各自的绝对 X/Y 坐标，不要求依次排列。点击“恢复自动定位”可恢复该行原有的两行边距逻辑。候选间距和文字字号也可微调。
- 背景可选纯色、整图拉伸、整图平铺和九宫格；九宫格中间列和中间行可以分别选择拉伸／平铺。装饰图层支持相同图片填充方式。
- “网格与选框”仅用于编辑，不写入皮肤。支持 75%、100%、150%、200% 预览；拖动坐标仍以 DIP 为单位。
- 撤销、重做各项模型修改，最多保留 100 次操作。“恢复源布局”可撤销；未保存退出时提示放弃草稿。
- “另存副本”保存并在主界面预览；“保存并应用”同时更改当前选择。所有保存生成新皮肤标识，保留作者、授权和 SSF 转换报告。对输入中的会话不执行清空或重建。

画布最小尺寸由背景属性控制。文字内容可能撑大画布；装饰图层不会撑大画布，以免锚点在拖动时漂移。更大的装饰空间需要主动增加最小宽高。

## 数据协议

沿用 `formatVersion: 1`，旧配置缺省时仍按原布局显示。新增能力会写入 `requiredCapabilities`：`decoration-layers`、`text-position`、`tiled-images`。不支持这些能力的渲染器应拒绝加载。装饰图片使用与背景一致的包内路径校验和资源预算。

```json
{
  "formatVersion": 1,
  "id": "example.layout",
  "name": "自由布局",
  "units": "dip",
  "requiredCapabilities": ["decoration-layers", "text-position", "tiled-images"],
  "layout": {
    "minWidth": 480,
    "minHeight": 180,
    "preeditPosition": { "x": 150, "y": 24 },
    "candidatePosition": { "x": 150, "y": 56 }
  },
  "background": {
    "image": "assets/background.png",
    "mode": "nineSlice",
    "slice": { "left": 24, "top": 12, "right": 24, "bottom": 12 },
    "horizontalFill": "tile",
    "verticalFill": "stretch"
  },
  "layers": [
    {
      "id": "decoration",
      "name": "右下装饰",
      "image": "assets/decoration.png",
      "anchor": "bottomRight",
      "x": -12,
      "y": -8,
      "width": 64,
      "height": 64,
      "opacity": 0.85,
      "plane": "behindText",
      "mode": "stretch",
      "visible": true
    }
  ]
}
```

锚点为 `topLeft/topCenter/topRight/centerLeft/center/centerRight/bottomLeft/bottomCenter/bottomRight`。图层 X/Y 是相对该锚定矩形的偏移；宽高与画布单位为 DIP。九宫格 slice 使用源图像素。`mode: tile` 按原图的 96 DPI 逻辑尺寸重复，九宫格只平铺相应中间分区，四角保持原尺寸。

最多 32 个图层；单图最多 800 万像素，当前皮肤全部不同图片最多 1600 万解码像素，编码文件总量最多 64 MiB。所有图层（包括隐藏图层）的资源都须存在。原生导入器现在会复制所有引用的图层资源，不只复制背景。

## 验证状态

自动检查包括保存事务、撤销／重做、非法修改回滚、源文件保留、资源复制、草稿清理、独立重载、锚点几何、透明度、遮挡顺序、平铺像素与九宫格边角，并在真实 Rime 正在组合时验证状态不变。

实际编辑器控件已离屏渲染检查；程序已成功打开。自动鼠标操作因检测到用户正在输入而停止，因此画布拖动尚未完成交互验收，不将离屏测试当作实际鼠标测试。
