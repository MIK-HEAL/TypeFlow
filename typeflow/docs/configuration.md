# 通过配置文件自定义皮肤

TypeFlow 的原生皮肤本来就是公开的数据文件，不依赖可视化编辑器。当前正式支持 **JSON / JSONC + 相对路径图片资源**。YAML 和 CSS 尚未实现；WPF 渲染器不会解释 CSS。将来可以通过独立配置解析器／导入器映射到同一个原生皮肤模型。

## 开始使用

1. 复制 `themes/config-example/` 到你自己的皮肤工作目录。
2. 用 VS Code 或其他文本编辑器打开 `theme.jsonc`。修改 `$schema` 使它指向本项目 `docs/theme.schema.json` 的正确相对路径或完整文件 URI，可获得字段提示；运行不依赖这个字段。
3. 在程序中点击“关联配置文件…”，选择此文件。也可直接选择任意文件名的 `.json` 或 `.jsonc`。
4. 在皮肤列表中选择带 `[关联]` 的条目进行预览；点击“应用到候选窗”持久应用。
5. 修改后保存，程序约每 1 秒检查并重载。也可点击“立即重载配置”。未修改的皮肤不会重复解码图片。

不复制模板也能直接关联项目内的示例文件进行测试。示例的中文注释说明了可修改的字段，且不依赖 SSF 素材。

“编辑配置文件”使用系统默认关联程序打开当前配置。右键该按钮选择“打开配置所在目录”。若当前为程序维护的默认皮肤，会先创建一个可编辑副本；其余库内皮肤直接编辑库内 `theme.json`，关联条目打开外部源文件。

JSONC 支持 `//`、`/* */` 注释以及末尾逗号。GUI 另存副本会生成普通 JSON；不会覆盖关联源文件、源文件的注释或其图片。

## 配置能控制什么

| 字段 | 能力 |
| --- | --- |
| `text`、`selection` | 字体、DIP 字号、普通／拼音／选中文字颜色及选中背景 |
| `layout` | 独立拼音／候选坐标、最小画布尺寸、候选间距、自动两行边距 |
| `background` | 背景色、图片、拉伸／平铺／九宫格及两轴中间区域填充 |
| `layers` | 装饰图层、图片、锚点、偏移、尺寸、不透明度、顺序、可见性 |
| `requiredCapabilities` | 显式声明必要能力；不支持时拒绝加载 |
| `extensions` | 不耦合到 SSF 的格式扩展数据 |

颜色为 `#AARRGGBB`，布局与字号单位为 DIP，九宫格切片边界使用源图像素。图片相对配置文件所在目录，例如 `assets/background.png`。资源不能使用 `..`、绝对路径或脚本；配置不会执行程序、下载 `$schema` 或读取网络样式表。

完整协议参阅 [原生皮肤 v1](theme-v1.md) 和 [高级布局](advanced-layout.md)；机器可读说明在 [theme.schema.json](theme.schema.json)。运行时校验还会检查图层 ID 唯一性、图片尺寸与预算、切片范围等跨字段规则，Schema 提示不能代替运行时校验。

## 导入与关联的区别

- **导入原生皮肤目录**：复制配置和引用资源，后续编辑的是库内副本。源目录修改不会同步。
- **关联配置文件**：记住源文件的完整路径，持续读取其配置与引用图片；源文件不移动、不覆盖，也不需要操作系统符号链接。
- **移除关联**：皮肤列表中的删除操作只移除库内条目和缓存；源文件与外部资源保持不变。删除正在应用的条目后恢复默认。
- **另存编辑结果**：高级编辑器创建独立原生副本，新副本不再跟随原配置文件变化。

关联记录保存在 `workspace/themes/user-link-*/link.json`。应用选择仍记录在 `workspace/active.json`。每个关联条目的 `theme.json` 和 `assets/` 是本地有效快照，手工编辑应通过“编辑配置文件”打开源文件，而不是编辑这些缓存。

合法修改通过图片解码、布局校验后才替换有效快照。写到一半的 JSON、缺图、无效图片和不支持的能力会在主界面显示错误；继续使用上一份有效快照，不清空输入或重建引擎。出错后会自动重试，修正后恢复。外部目录暂时不可用、程序重启时，也可使用已缓存的皮肤。

图片缓存按内容哈希命名，保证更新图片不破坏旧快照；修改纯文本通常不会产生新图片。暂不自动回收关联条目里旧图片的内容版本，频繁替换大图可能增加磁盘占用；删除条目会一并清理其本地缓存。

## 命令行

在仓库根目录执行：

```powershell
# 校验配置及图片，不打开界面。
dotnet typeflow/build/config-app/TypeFlow.Desktop.dll --validate "typeflow/themes/config-example/theme.jsonc"

# 添加关联，只注册到列表，不改变当前选择。
dotnet typeflow/build/config-app/TypeFlow.Desktop.dll --link "D:\MySkins\paper\theme.jsonc"

# 添加并应用。
dotnet typeflow/build/config-app/TypeFlow.Desktop.dll --link "D:\MySkins\paper\theme.jsonc" --apply
```

本次构建位于 `build/config-app/`；通过通用 `Build.ps1` 构建后也可使用 `build/app/` 下相同的命令。命令行和 GUI 使用同一套皮肤库及校验规则。

系统候选窗宿主也接入了相同配置监测机制，但完整 Windows 系统输入法仍需按小狼毫接入记录继续验收；此功能不代表 TSF 已安装。
