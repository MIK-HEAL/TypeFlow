TypeFlow 输入法 · 安装预览版

双击 setup.exe，允许 Windows 管理员授权，按向导完成安装。
完成页可勾选“启用 TypeFlow 并打开皮肤设置”；首次启动自动准备简体拼音词库。
也可使用 Win + 空格选择 TypeFlow IME Preview。Shift 切换中英文。

开始菜单 → TypeFlow 输入法：
  启动 TypeFlow：启动服务并切换到 TypeFlow。
  输入法设定：打开原有的方案和小狼毫外观设置。
  皮肤设置：导入 SSF、选择皮肤、编辑布局，再应用到系统输入法。
  打开用户配置：打开当前用户的配置、词库目录。
  重新部署：修改配置后重新加载。
  卸载：移除输入法及程序，保留用户配置和词库。

用户配置默认位于 %LOCALAPPDATA%\TypeFlow\Ime。
可修改 default.custom.yaml、weasel.custom.yaml，然后重新部署。

托盘菜单中也有独立的“输入法设定”和“皮肤设置”。
皮肤设置中选中皮肤后，点击“应用到系统输入法”。关闭设置窗口后皮肤仍生效。
支持图片、装饰图层、文字位置、九宫格和拉伸方式；也可随时选择“使用系统原生候选窗”。
自定义候选窗当前使用键盘选词，尚不支持鼠标点击候选；皮肤后台退出时回退原生窗口。
导入的皮肤和设置保存在当前用户的 %LOCALAPPDATA%\TypeFlow\Skins，卸载后保留。
浏览器关闭窗口后可能仍在后台运行。升级后如仍显示旧候选窗，请完全退出并重开浏览器。
桌面或资源管理器也可能保留旧组件。注销 Windows 后重新登录会让所有应用加载新组件。
