# TypeFlow {{VERSION}} — 皮肤工作台体验版

首个 Windows x64 便携体验包。下载 ZIP 后完整解压，双击 **TypeFlow.exe**；无需预装 .NET。

## 可以体验

- “纸间”“夜航”两套自有示例皮肤。
- 普通 ZIP SSF 导入、原生皮肤目录导入、JSON/JSONC 配置关联。
- 静态 PNG、九宫格、平铺和装饰图层预览。
- 拖动布局、调整字号、撤销/重做、保存独立副本。
- 保留导入兼容报告；外部配置无效时保留有效预览。

## 本次范围

这是皮肤工作台 Alpha，默认使用明确标注的演示候选。**不是已注册的系统输入法**；在记事本、浏览器等应用中仍使用原输入法。本包不附带 Rime 运行时、第三方词库或第三方 SSF 素材；高级连接方式见包内 ADVANCED.txt。

仅发布 Windows x64 用户体验包；Linux/macOS 继续进行共享组件和界面验证。当前不支持动画、加密 SSF、竖排及完整搜狗皮肤兼容。

## 下载与校验

下载 TypeFlow-{{VERSION}}-win-x64.zip 和同名 .sha256 文件。解压后请保留全部文件；不要只复制 exe。此包未做代码签名。
