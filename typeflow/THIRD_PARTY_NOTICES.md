# Third-party sources and assets

The first distributable target is the Windows skin-workbench Alpha ZIP. Its exact dependency inventory and notices are generated by scripts/Write-PackageNotices.ps1. Other development runtimes below are separate and are not included in that ZIP.

- TypeFlow-specific original code and bundled first-party themes use BSD-3-Clause; see `LICENSE`. This does not relicense upstream sources, dependencies, or user-provided skins.

- The surrounding librime checkout is BSD-3-Clause; see `../LICENSE`.
- The optional cross-platform workbench uses Avalonia 12.1.5 (MIT), Fluent styles and its Skia/HarfBuzz rendering dependencies. Direct versions are in `Avalonia.props`; all resolved package versions and content hashes are in the three Avalonia project `packages.lock.json` files. The existing shared components and WPF application do not reference these packages. Preserve Avalonia, SkiaSharp/Skia, HarfBuzz and other transitive native package notices when preparing a distributable; this prototype does not yet provide a complete binary redistribution inventory.
- `native/rime_bridge.cpp` calls its public API. The local development runtime comes from the official librime 1.17.0 clang x64 release. That release's `version-info.txt` also lists librime-lua (`ec52e48`), librime-octagram (`dfcc151`) and librime-predict (`920bd41`). A minimal custom runtime or a complete dependency and plugin license inventory is required before packaging for distribution.
- Rime's dependency archive supplies OpenCC conversion data and upstream native dependencies. See the respective projects' license terms; do not assume the top-level BSD license covers all binaries and data.
- The fetched `rime-luna-pinyin`, `rime-prelude`, and `rime-essay` snapshots include LGPL-3.0 license files, preserved in `rime-data/licenses/`. Repositories, immutable commits and archive hashes are recorded in `sources.json`.
- Optional Weasel 0.17.4 is GPL-3.0. The downloaded source retains its license. `integration/weasel/Apply-Bridge.ps1` modifies only its optional UI integration points and keeps a backup. Distributing a modified Weasel requires preserving its license and supplying corresponding source and changes.
- The SSF test fixture was supplied by the user. Its `General/skin_author` is `忧郁游戏`. Its images and derived screenshots are for local testing; no redistribution license has been declared. The original fixture is never modified and the converted artwork is not included in the product source tree.
- `fkxxyz/ssfconv` (GPL-3.0) was consulted to check BGR color order and the order of SSF margin fields. Its code and dependencies are not bundled or executed. The initial ZIP importer is implemented separately with .NET's built-in compression and encoding facilities; encrypted SSF conversion is not implemented.

The workbench Alpha excludes librime binaries/plugins, third-party dictionaries, Weasel and the SSF fixture. Adding any of those to a later user package requires a corresponding source/license inventory for that package.

The separate Windows IME installer is currently a local installation preview, not an approved public release. It includes the native Weasel/Rime runtime and data, retains the Weasel GPL license and dictionary licenses, and emits a sidecar source archive with the pinned Weasel source and transformation/installer scripts. Its payload manifest hashes every bundled file. The full Rime binary/plugin/transitive dependency source and license inventory remains a public-release prerequisite. The installer compiler is pinned project-local NSIS 3.12 and is not copied into the installed payload.
